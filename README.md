 Eman Hashimi Portfolio

A responsive cream/black minimalist portfolio inspired by the supplied Framer portfolio.

 Files
- src/main.tsx — app entry (React Router provider)
- src/App.tsx — routes
- src/components/ — Navbar, Hero, StackedMockups, SkillsSection, ProjectCard, PageTitle, ContactForm, Footer, Layout, Button, ScrollToTop
- src/pages/ — Home, About, Projects, Contact
- src/data/projectsData.ts — projects + selected work
- src/index.css — Tailwind theme, base styles, .shell container
- src/assets/images/ — project images

 Stack: React + TypeScript, Vite, Tailwind CSS v4, React Router, Framer Motion.

 Scripts: `npm run dev` · `npm run build` · `npm run lint` · `npm run preview`

Live demo : https://eiman16-edge.github.io/eman-portfolio/
