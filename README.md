# Eman Hashimi Portfolio

A responsive cream/black minimalist portfolio inspired by the supplied Framer portfolio.

## Files
- index.html — Home
- about.html — About
- projects.html — Projects
- contact.html — Contact
- css/style.css — all styling
- js/script.js — mobile menu, form message, current year

## Important
Replace the Unsplash image URLs in the HTML with your own portfolio/project images.
Replace the # project links and social links with your real URLs.
The contact form is front-end only; connect it to Formspree, Netlify Forms, EmailJS, or your own backend to receive submissions.
